## 什么是高级规则？

在前一篇文章中，我们介绍了普通规则的配置方法——通过界面上的表达式编辑器，选择测点、运算符和阈值，用 AND / OR 组合出判断条件。普通规则足以应对大部分"单测点越限"或"多测点简单组合"的场景。

但在实际工作中，工程师经常会遇到更复杂的告警需求：

- 需要对测点做数学运算后再判断（如计算效率、热耗率）
- 需要基于时间窗口做统计（如"5 分钟内均值超限"）
- 需要引用多个测点之间的关系（如温差、压差的变化率）
- 需要加入条件分支逻辑（如"仅在机组负荷 > 80% 时才判断"）

这些场景下，普通规则的表达式编辑器就不够用了。**高级规则**允许你直接编写 Python 脚本来定义告警判断逻辑，拥有完整的编程灵活性。

---

## 创建高级规则的入口

1. 登录系统，进入 **建模平台 > 配置中心**。
2. 在左侧导航树中选择目标 **电厂 > 机组 > 系统 > 设备**。
3. 点击 **"规则"** 页签。
4. 点击 **＋ 创建规则**，在弹出的页面中：
   - 填写规则名称、描述等基本信息。
   - **规则类型选择"高级"**（而非"普通"）。
   - 选择告警级别。
5. 点击 **"保存"**，进入规则配置编辑页面。

> 💡 **提示**：高级规则同样支持锁定机制。保存后系统会自动分配版本号，创建者可锁定规则，防止他人误改。

---

## 脚本编辑器界面说明

进入高级规则的编辑页面后，你会看到一个 **Python 脚本编辑器**，这是与普通规则最大的区别。编辑器区域主要包括：

- **脚本编写区**：在此处编写 Python 代码，定义告警判断逻辑。
- **引用测点列表**：展示当前规则可引用的所有测点（包括原始测点和计算测点）。你可以在脚本中通过测点编码来读取对应的实时值。
- **调试 / 预览区**：编写完成后，可选择一段历史时间范围进行脚本预览，查看在该时间段内脚本是否会正确触发告警。

## 脚本编写要点

### 1. 读取测点值

在脚本中，通过系统提供的内置函数读取测点的实时数据。常用方式如下：

```python
# 读取某个测点的当前值
temp_value = get_sensor_value("JQRD_GT_EXH_TEMP_001")

# 读取某个计算测点的值
efficiency = get_sensor_value("CALC_THERMAL_EFF")
```

测点编码可在右侧"引用测点列表"中查看并复制，避免手动输入出错。

### 2. 编写判断逻辑

脚本的核心是返回一个布尔值——`True` 表示触发告警，`False` 表示正常。

```python
# 示例：当排气温度 > 550℃ 且负荷 > 80% 时触发告警
exhaust_temp = get_sensor_value("JQRD_GT_EXH_TEMP_001")
load = get_sensor_value("JQRD_GT_LOAD_001")

if exhaust_temp > 550 and load > 80:
    alarm = True
else:
    alarm = False
```

### 3. 使用数学运算

高级规则的优势在于可以进行任意复杂度的数学计算：

```python
# 示例：计算温差变化率，超过阈值时告警
import math

temp_in = get_sensor_value("JQRD_GT_INLET_TEMP")
temp_out = get_sensor_value("JQRD_GT_OUTLET_TEMP")
delta_t = abs(temp_out - temp_in)

# 温差超过 200℃ 时告警
alarm = delta_t > 200
```

### 4. 基于时间窗口的统计判断

如果需要基于一段时间内的数据做判断（如均值、最大值），可使用系统提供的时间窗口函数：

```python
# 获取最近 5 分钟内的排气温度均值
avg_temp = get_sensor_avg("JQRD_GT_EXH_TEMP_001", window="5m")

# 均值超过 540℃ 时告警
alarm = avg_temp > 540
```

常用的时间窗口函数包括：`get_sensor_avg`（均值）、`get_sensor_max`（最大值）、`get_sensor_min`（最小值）。时间窗口参数支持 `s`（秒）、`m`（分钟）、`h`（小时）格式。

### 5. 条件分支与多级判断

```python
# 仅在机组运行状态下才进行判断
load = get_sensor_value("JQRD_GT_LOAD_001")
vibration = get_sensor_value("JQRD_GT_VIB_001")

if load < 30:
    # 低负荷或停机状态，不触发告警
    alarm = False
elif load < 80:
    # 中等负荷，振动阈值放宽
    alarm = vibration > 12
else:
    # 高负荷，振动阈值收紧
    alarm = vibration > 8
```

## 脚本调试与预览

编写完成后，务必先进行调试：

1. 在编辑器下方选择一段 **历史时间范围**。
2. 点击 **"预览"**。系统会基于该时间段的历史数据运行你的脚本，在测点曲线上方以红色标线显示模拟告警。
3. 检查告警是否在预期的时间点触发，确认无误报或漏报。
4. 如果脚本存在语法错误，系统会在预览时给出错误提示，根据提示修正代码即可。

> ⚠️ **注意**：预览只是模拟，不会产生真实告警。正式生效需要启用规则（见下一步）。

---

## 启用与上线

脚本调试满意后：

1. 返回规则配置编辑页面顶部，点击 **"启用"** 按钮。
2. 输入版本描述信息（建议写明本次修改的内容，方便后续追溯）。
3. 确认启用。

启用后，该高级规则将出现在 **趋势监测 > 规则监测** 页签中，系统开始基于你的 Python 脚本实时判断并上报告警。

## 常见问题

**Q：高级规则的脚本支持哪些 Python 库？**
A：系统内置了基础数学库（如 `math`），但出于安全考虑，不支持 `os`、`sys` 等系统级库，也不支持网络请求。如需复杂计算，建议先通过计算测点预处理数据，再在高级规则中引用。

**Q：高级规则和计算测点 + 普通规则的组合方案，如何选择？**
A：如果你的需求是"先做计算、再做简单越限判断"，推荐用计算测点 + 普通规则，更易维护。如果判断逻辑本身就很复杂（如多分支、动态阈值），用高级规则更直接。

**Q：脚本修改后需要重新启用吗？**
A：是的。每次修改脚本并保存后，系统会生成新版本，你需要重新点击"启用"才能让新逻辑生效。旧版本产生的告警不受影响。
