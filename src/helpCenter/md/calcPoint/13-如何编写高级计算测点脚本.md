## 普通计算测点的局限

在上一篇文章中，我们介绍了如何通过可视化表达式编辑器创建计算测点。编辑器内置了四则运算、统计函数、三角函数和时间窗口函数，能覆盖大部分常规需求。

但在以下场景中，可视化编辑器会显得力不从心：

- 需要条件分支逻辑（如"负荷 > 80% 时用公式 A，否则用公式 B"）
- 需要多步中间变量的复杂推导（如多级热力学计算）
- 需要对数组或序列数据做循环处理
- 需要引用自定义的工程常数表或分段函数

这些场景下，**高级计算测点**允许你直接编写 Python 脚本来定义计算逻辑，获得完整的编程灵活性。

---

## 创建高级计算测点

1. 登录系统，进入 **建模平台 > 配置中心**。
2. 在左侧导航树中选择目标 **电厂 > 机组 > 系统 > 设备**。
3. 点击 **"计算测点"** 页签。
4. 点击 **＋** 按钮，进入"新增计算测点"页面。
5. 填写基本信息（编码、名称、描述），其中计算测点编码必须全局唯一。
6. **计算方式选择"高级"**（而非"普通"），页面将切换为 Python 脚本编辑器。

> ⚠️ **注意**：计算测点编码保存后不可修改。高级计算测点与普通计算测点的编码共享同一命名空间，不能重复。

---

## 脚本编辑器界面

选择高级模式后，表达式编辑器区域会替换为一个 **Python 脚本编辑器**，主要包含：

- **代码编写区**：在此处编写 Python 代码，定义计算逻辑。
- **可引用测点列表**：展示当前机组下所有可用的测点（原始测点和其他计算测点），点击可复制编码到脚本中。
- **预览区**：编写完成后，可选择一段历史时间范围运行脚本，预览输出结果。

## 脚本编写要点

### 1. 读取测点值

通过系统内置函数获取测点的实时数据：

```python
# 读取原始测点
inlet_temp = get_sensor_value("JQRD_GT_INLET_TEMP")
outlet_temp = get_sensor_value("JQRD_GT_OUTLET_TEMP")
load = get_sensor_value("JQRD_GT_LOAD_001")

# 也可以读取其他计算测点
delta_t = get_sensor_value("CALC_TEMP_DIFF")
```

### 2. 返回计算结果

脚本的最终目的是计算出一个数值，并赋值给内置变量 `result`。系统会将 `result` 的值作为该计算测点的输出。

```python
# 示例：计算排气温度与进气温度的差值
inlet_temp = get_sensor_value("JQRD_GT_INLET_TEMP")
outlet_temp = get_sensor_value("JQRD_GT_OUTLET_TEMP")

result = outlet_temp - inlet_temp
```

> ⚠️ **注意**：脚本必须最终给 `result` 赋值，否则计算测点无法输出有效数据。

### 3. 条件分支计算

高级计算测点最大的优势在于支持条件逻辑：

```python
# 示例：根据负荷区间使用不同的效率修正公式
load = get_sensor_value("JQRD_GT_LOAD_001")
heat_input = get_sensor_value("JQRD_GT_HEAT_INPUT")
power_output = get_sensor_value("JQRD_GT_POWER_OUTPUT")

base_efficiency = power_output / heat_input * 100

if load >= 80:
    # 高负荷：直接使用基础效率
    result = base_efficiency
elif load >= 50:
    # 中负荷：加修正系数
    result = base_efficiency * 1.02
else:
    # 低负荷：加更大的修正系数
    result = base_efficiency * 1.05
```

### 4. 多步中间变量

对于复杂的工程计算，可以使用中间变量分步推导，保持代码可读性：

```python
import math

# 读取测点
p1 = get_sensor_value("JQRD_GT_PRESS_IN")   # 进口压力
p2 = get_sensor_value("JQRD_GT_PRESS_OUT")  # 出口压力
t1 = get_sensor_value("JQRD_GT_TEMP_IN")    # 进口温度 (℃)

# 中间计算
pressure_ratio = p2 / p1
t1_kelvin = t1 + 273.15
gamma = 1.4  # 比热比常数

# 等熵温度
t2_ideal = t1_kelvin * math.pow(pressure_ratio, (gamma - 1) / gamma)

# 输出等熵温升
result = t2_ideal - t1_kelvin
```

### 5. 时间窗口统计

与高级规则类似，高级计算测点也可以使用时间窗口函数：

```python
# 最近 10 分钟排气温度均值与当前值的偏差
current_temp = get_sensor_value("JQRD_GT_EXH_TEMP_001")
avg_temp_10m = get_sensor_avg("JQRD_GT_EXH_TEMP_001", window="10m")

result = current_temp - avg_temp_10m
```

常用时间窗口函数：`get_sensor_avg`（均值）、`get_sensor_max`（最大值）、`get_sensor_min`（最小值）。时间参数支持 `s`（秒）、`m`（分钟）、`h`（小时）格式。

## 预览与调试

脚本编写完成后，建议先进行预览验证：

1. 在编辑器下方选择一段 **历史时间范围**。
2. 点击 **"预览"**，系统会基于历史数据运行脚本，以曲线图形式展示计算结果。
3. 检查输出曲线是否符合预期——数值范围是否合理、是否存在异常跳变。
4. 如果脚本存在语法错误或运行异常，系统会给出错误提示，根据提示修正即可。

---

## 保存与版本管理

预览满意后，点击 **"保存"**：

- 系统自动分配版本号。
- 计算测点出现在"计算测点"页签列表中，可被同一机组下的模型、规则和其他计算测点引用。
- 后续修改会生成新版本，所有引用方会收到版本升级通知。对于在线模型和规则，需要手动执行热更新。

## 高级计算测点 vs 普通计算测点：如何选？

| 维度 | 普通计算测点 | 高级计算测点 |
|------|-------------|-------------|
| 编辑方式 | 可视化表达式编辑器 | Python 脚本 |
| 适用场景 | 简单数学运算、统计函数 | 条件分支、多步推导、自定义逻辑 |
| 上手门槛 | 低，拖拽选择即可 | 需要基础 Python 编程能力 |
| 可维护性 | 表达式直观，他人易读 | 需要写注释保持可读性 |
| 推荐策略 | 能用普通就用普通 | 普通搞不定时再用高级 |

> 💡 **提示**：两种类型在系统中地位相同——都可以被模型、规则和其他计算测点引用，告警和版本管理机制也完全一致。区别仅在于定义计算逻辑的方式不同。

## 常见问题

**Q：高级计算测点支持哪些 Python 库？**
A：支持基础数学库（如 `math`），但出于安全限制，不支持 `os`、`sys`、`requests` 等系统和网络库。

**Q：脚本中能引用其他计算测点吗？**
A：可以。通过 `get_sensor_value` 传入其他计算测点的编码即可读取其输出值，支持链式引用。但注意避免循环引用（A 引用 B，B 又引用 A），系统会在保存时检测并阻止。

**Q：`result` 可以返回非数值类型吗？**
A：不可以。计算测点的输出必须是一个数值（整数或浮点数）。如果脚本运行后 `result` 为 `None` 或非数值类型，系统会标记该测点数据为无效。
