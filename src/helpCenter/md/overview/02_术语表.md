# 术语表

> **文档类型**：参考
> **适用角色**：全部用户
> **用途**：速查系统中的关键名词，按主题分组

本表收录燃机故障预警及诊断系统中的常用术语，供查阅参考。概念之间的关系见 [核心概念](#核心概念)。

---

## 测点与数据

| 术语 | 含义 |
| --- | --- |
| 原始测点 | 从设备测点直接获取的原始数据 |
| 计算测点 | 对原始测点进行计算后得到的派生数据 |
| 普通计算测点 | 通过可视化表达式编辑器定义的计算测点 |
| 高级计算测点 | 通过 Python 脚本定义计算逻辑的计算测点 |
| 测点编码 | 测点的全局唯一标识，不可与其他测点重复 |
| 实际值 | 测点采集到的真实测量数据 |
| 预测值 | AI 模型对测点的预测输出，代表正常应有水平 |
| 残差 | 实际值 − 预测值，偏差越大越可能异常 |

---

## 模型与规则

| 术语 | 含义 |
| --- | --- |
| 模型 | 基于测点历史数据、机器学习算法训练的抽象模型，可预测测点信息 |
| 规则 | 手动定义的判断方法，用表达式或脚本处理测点数据 |
| 普通规则 | 通过可视化表达式编辑器配置的规则 |
| 高级规则 | 通过 Python 脚本定义判断逻辑的规则 |
| 告警监测间隔 | 模型 / 规则执行计算与判断的时间间隔 |
| 热更新 | 在线模型 / 规则修改后，无需停用即可让新版本生效的更新方式 |
| IO 类型 | 测点在模型中的角色，如输入、输出、输入&输出、不使用 |

---

## 触发器与版本

| 术语 | 含义 |
| --- | --- |
| 全局触发器 | 决定计算测点刷新频率的"时钟"，统一管理、只绑定计算测点 |
| 时间粒度 | 触发器的执行频率级别（天 / 小时 / 分钟 / 秒 / Cron / 事件） |
| 版本号 | 模型、规则、计算测点修改后自动分配的版本标识 |
| 运行版 | 正在线上运行的版本，只读不可改 |
| 历史版 | 历史保留的版本，只读且不可激活 |
| 编辑版 | 处于编辑状态的版本，一个对象同时只能有一个 |
| 锁定 | 编辑时对象被占用、仅编辑者可改的状态 |

## 告警

| 术语 | 含义 |
| --- | --- |
| 告警 | 模型或规则检测到异常时上报的信息，是模型/规则的输出 |
| 告警级别 | 告警的严重程度分级（如二级告警、三级告警） |
| 告警类型 | 告警的产生来源，如模型告警、预警告警 |
| 告警类别 | 告警的数据来源类别，如原始告警 |
| 实时告警 | 系统自动生成、尚未进入处理流程的告警 |
| 处理中告警 | 正处于流程处理中的告警 |
| 归档告警 | 已结束流程处理并关闭的告警 |
| 待办告警 | 待处理的告警 |
| 首次预警 | 该告警首次出现的时间 |
| 最近预警 | 该告警最近一次出现的时间 |
| 预警次数 | 该告警累计触发的次数 |
| 持续时间 | 该告警从首次到最近预警的持续时长 |
| 超限比例 | 实际值超出预测值的比例 |
| 告警延迟策略 | 条件持续满足一段时间后才上报告警的防误报机制 |

---

## 告警处理

| 术语 | 含义 |
| --- | --- |
| 归档 | 对告警做最终处理的动作，含关闭 / 忽略 / 误报 |
| 关闭 | 确认告警已处理完毕，关闭归档 |
| 忽略 | 确认无需处理，直接归档 |
| 误报 | 标记为错误告警并归档，单独统计不计入有效告警 |
| 挂起 | 暂不处理、保留在待办的状态（不等于关闭） |
| 告警单 | 走正式流程处理的工单，按流程图分派和处理 |
| 故障诊断 | 分析告警原因、对比测点、给出处理建议的页面 |

---

## 监测页面

| 术语 | 含义 |
| --- | --- |
| 模型监测 | 查看模型实时运行与告警的页面，曲线含实际值/预测值/残差 |
| 规则监测 | 查看规则实时运行与告警的页面，曲线仅含实际值 |
| 实时监测 | 展示测点实时曲线的页签 |
| 历史仿真 | 用当前模型配置回放过去会否告警的模拟功能（非真实记录） |
| 历史告警 | 系统过去实际产生的告警记录 |
| 告警点 | 测点曲线上方标识状态的彩色点：红=有预警，绿=正常 |
| 实时更新开关 | 让告警列表随新告警自动刷新的开关 |

## 知识库与统计

| 术语 | 含义 |
| --- | --- |
| 知识库 | 基于专家领域知识构建的故障知识库，含 FMEA 库和案例库 |
| FMEA 库 | 故障模式与影响分析库，存储故障模式、原因和维修建议 |
| 故障模式 | 一种可能的故障情形，含现象、影响、监测测点、原因 |
| 案例库 | 实际告警处理记录沉淀成的案例集合 |
| 告警准确率 | 有效告警占总告警的比例，反映模型/规则配置质量 |
| 告警处理率 | 已处理告警占总告警的比例，反映团队响应速度 |
| 案例转化率 | 告警单转化为案例的比例，反映知识沉淀程度 |

## 系统管理

| 术语 | 含义 |
| --- | --- |
| 权限 | 用户对某资源可执行的操作集合 |
| 角色 | 权限的集合，用于批量分配给用户 |
| 用户组 | 共享相同角色的用户集合 |
| RBAC | 基于角色的访问控制，本系统的权限管理机制 |
| LDAP | 企业统一身份管理协议，本系统支持从中同步用户 |
| 设备树 | 电厂 → 机组 → 系统 → 设备的层级导航结构 |
| 流程图 | 定义告警单处理步骤的工作流配置 |
