# 如何配置测点参数(残差阈值与告警级别)

> **模块**:模型配置 · **角色**:工程师 · **配套视频**:V1 · 04:00 起

测点选好、模式配好之后,下一步就是**为每个测点单独配置告警参数**——决定残差多大算异常、超限多久才报警、告警是几级。本篇覆盖测点参数页签的所有字段及编辑方式。

---

## 一、什么时候用它

- 新建模型保存后,**首次进入「模型配置」编辑页面**时
- 模型已上线后,需要**调整某些测点的灵敏度**(误报多 / 漏报多)
- 新增测点后,需要为新测点补充参数

> 💡 **省事方案**:如果你在 #1 基本信息里勾选了「**是否计算阈值 = 是**」,系统会在训练时自动为每个测点算出残差阈值,这一步**可以跳过**。
>
> 但即使勾了自动计算,**告警级别、IO 类型**仍需要手动配置,所以本篇建议完整阅读。

## 二、入口

在「模型配置」编辑页面 → 中间位置找到 **「训练采样时间」** 和 **「测点参数」** 双页签 → 切换到 **「测点参数」** 页签 → 看到所有测点列表。

`[配图:模型配置编辑页面-测点参数页签-测点列表]`

## 三、字段说明

每个测点对应一行,包含以下可配置参数:

### 1. 残差告警下限 / 残差告警上限

模型预测值与实际值的差值称为**残差**。当残差超出 `[下限, 上限]` 范围时,触发告警。

- 数值可正可负(残差有方向)
- 上限通常 > 0,下限通常 < 0
- 数值越大(绝对值)→ 越不敏感,告警少;反之越敏感,告警多

### 2. 残差超限持续比例阈值

**单次告警的“持续度”要求**——残差在一个评估窗口内,有多少比例的时间超限才算告警。

- 取值 0~1,例如 0.5 表示窗口内一半以上时间残差超限才告警
- 用于过滤瞬时毛刺,避免数据抖动导致的误报

### 3. 残差超限时间比例阈值

**告警“频率”要求**——某段时间内有多少比例属于"超限状态"才算告警。

> 📝 这两个比例参数(持续 / 时间)的具体取值,手册没给推荐区间,建议工程师代表给一个默认值供运营写入。

### 4. 级别(告警级别)

下拉选择,通常包括:
- **一级告警**(最高)
- **二级告警**
- **三级告警**(最低)

告警级别决定后续告警的颜色标识、推送优先级、看板展示位置。**生产环境建议至少明确区分两级**——核心保护测点设为一级,辅助参考测点设为二级或三级。

### 5. IO 类型

决定测点在模型中的角色:

| 类型 | 含义 | 是否参与训练 | 是否产生告警 |
| --- | --- | --- | --- |
| **输入** | 正常测点,参与模型预测和告警判断 | ✅ 是 | ✅ 是 |
| **不使用** | 仅作参考显示,曲线图只显示实际值,不参与训练 | ❌ 否 | ❌ 否 |

> 💡 **使用场景**:有些测点想"看一眼对照",但不希望它影响模型——设为「不使用」即可。训练页面会用**无色底纹**标识这类测点。

## 四、编辑方式

### 方式 1:单个测点快速改

**双击测点行的参数值** → 直接修改 → 失焦或回车保存。

适合微调单个测点的某个值。

### 方式 2:批量编辑

1. 在测点列表中**勾选多个测点**(支持全选)
2. 点击列表上方的 **「编辑」**
3. 弹出「**模型测点信息**」面板,统一修改参数 → 保存
4. 所选测点的参数一次性更新

`[配图:测点参数页签-批量编辑面板]`

### 方式 3:点击「编辑测点参数」(进入详情面板)

点击页签上方的 **「编辑测点参数」** 按钮 → 弹出独立的「**模型测点信息**」页面 → 完整呈现所有测点参数,支持搜索、排序、双击编辑。适合做整体梳理。

> 💡 **搜索**:页面右上角搜索框,支持按**名称**或**测点编码**模糊查询、通配符查询。

## 五、列表排序

测点列表中的参数列(残差阈值、级别等)**支持升序 / 降序排列**。

> ⚠️ **重要**:这里的排序**只影响当前页面的显示顺序**——
> - **不会**改变 #3 测点选取时定义的测点顺序
> - **不会**影响下方测点曲线的顺序
>
> 想真正调测点顺序,要回到「测点选取」页签(详见 #3)。

## 六、修改后的影响

| 操作 | 是否需要重训 |
| --- | --- |
| 调整残差告警上下限 | **否**(立即生效) |
| 调整持续 / 时间比例阈值 | **否**(立即生效) |
| 修改告警级别 | **否**(立即生效) |
| 修改 IO 类型(输入 → 不使用,或反之) | **是**(模型结构变了) |

> ⚠️ 修改 IO 类型相当于调整了参与训练的测点集合,系统会提示"需重新训练"。其他参数调整不影响训练结果,可以热更新。

## 七、常见疑问

**Q1:残差告警上下限该填多少?**

如果在基本信息勾选了「是否计算阈值 = 是」,首次训练后系统自动填充。上线运行一段时间后,根据误报 / 漏报情况微调:**误报多 → 把范围扩大**;**漏报多 → 把范围收紧**。

**Q2:批量编辑能改 IO 类型吗?**

可以。批量面板里的每个参数都可改,IO 类型也包含在内。批量改 IO 类型后会触发重训提示。

**Q3:页面排序会不会保存?**

不会。这里的排序仅当前会话有效,刷新或重新进入页面会回到默认顺序。

**Q4:为什么有的测点曲线上方有橘色线?**

那是系统提示该测点的实际数据**超出了可用训练数据范围**——意味着上线后遇到了训练时没见过的工况。需要回到 #6 重新采样训练。
